# reels-montage

Скилл для рилсов, где автор говорит в камеру, а кадр достраивается анимацией: мемы, нарисованные схемы, интерфейсы, скриншоты источников, инфографика. Он собран из работы над рилсом «Мясной прокси» и опирается на три вещи: принципы автора, общую Remotion-основу и монтажный стол для выбора. Скилл задаёт рамку, но не ограничивает: сцены придумываются под каждый ролик.

**Перед любой работой прочитай [references/principles.md](references/principles.md).** Там то, что автор уже объяснял и не должен объяснять снова: не дублировать голос плашками, подписи только по необходимости, когда уходить во весь кадр, без пауз, субтитры неприкосновенны, единый стиль, мемы по их механике, только реальные источники.

## Порядок работы

1. **Материал.** Расшифровка и правки распознавания (`template/subs.py`), транскрипт читается целиком.
2. **Структура.** Хук первой фразой. Схемы — в [references/structures.md](references/structures.md). Если нужен перемонтаж, склейки ставятся по тишине и проверяются повторным распознаванием (`template/recut.py`). Если автор просит, делается и сокращённая версия.
3. **Разметка кадра.** Граница камеры и скринкаста меряется по пикселям. Исходники раскладываются на `camera.mp4`, `site.mp4`, `voice.m4a` (см. [references/pipeline.md](references/pipeline.md), § 2).
4. **Монтажные сценарии.** 2–3 варианта разного характера с общей нумерацией сцен, таблицей «тайминг | что говорю | что в кадре» в `СЦЕНАРИИ.md`. Для каждой сцены сначала вопрос: что картинка добавляет к голосу? Если ничего, сцене хватит скринкаста или лица.
5. **Remotion.** `template/` копируется в `<ролик>/монтаж/`, потом `npm install`. Варианты пишутся на примитивах `lib.tsx`, каждая сцена проверяется стоп-кадром глазами. Варианты можно отдать параллельным форкам.
6. **Сборка вариантов.** `build.sh`: рендер, субтитры, при желании визитка.
7. **Монтажный стол.** `template/стол/`: `scenes.json` → `prep.py` → `server.py`. Автор выбирает сцены и пишет заметки, выбор ложится в `selection.json` и в MD.
8. **Финал.** `Final.tsx` из выбранных сцен с правками. Неоднозначную заметку сначала уточнить (особенно шутки и мемы), всё привести к одному стилю. Если есть досъёмка, собираются вставки (`I*.tsx`) и версия с ними и без них.
9. **Проверка перед сдачей.** Стоп-кадр каждой сцены, расшифровка стыков, синхрон звука, длительность. В ответе автору перечислить сделанное и отдельно то, что сделано по догадке.

## Что где

| Файл | Зачем |
|---|---|
| [references/principles.md](references/principles.md) | принципы автора с цитатами — читать первым |
| [references/structures.md](references/structures.md) | схемы рилса: «слово» и «кейс/рубрика» (пример NAAU) |
| [references/pipeline.md](references/pipeline.md) | техника: перемонтаж, разметка кадра, Remotion, стол, вставки, склейка, грабли |
| `template/src/lib.tsx` | основа: `Base`, `Bottom`, `Full`, мемы, штампы, чат, палитра, шрифты |
| `template/src/chat3.tsx`, `chars2.tsx` | реакции, голосовое, клавиши; нарисованные персонажи |
| `template/src/versions.tsx`, `Mix.tsx`, `Root.tsx`, `project.json` | регистрация версий и сборка по выбору |
| `template/recut.py` | перемонтаж по отрезкам, перенос субтитров, поиск тишины |
| `template/subs.py` | расшифровка whisper и субтитры в стиле рилс (фразы по 2–4 слова, активное слово жёлтым) |
| `template/build.sh`, `build-ins.sh` | сборка версии и вставки |
| `template/стол/` | монтажный стол: сервер, страница, подготовка медиа |

Живой пример — [examples/code/Final.tsx](examples/code/Final.tsx), итоговая сборка «Мясного прокси»: 11 сцен на примитивах шаблона.
