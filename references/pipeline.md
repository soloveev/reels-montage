# Техника: от записи до финала

Скилл вырос из работы над рилсом «Мясной прокси» (рубрика «Цифровой словарь»). Код итоговой сборки этого ролика лежит в [`examples/code/Final.tsx`](../examples/code/Final.tsx): одиннадцать сцен на примитивах шаблона. Когда не знаешь, как сделать сцену, сначала посмотри, как это решено там.

## 1. Материал и перемонтаж

Расшифровка — `template/subs.py transcribe` (whisper-cli, модель large-v3-turbo), правки распознавания — в `fixes.txt` (строка `было => стало`), субтитры — `subs.py build` и `burn`. Транскрипт читается целиком, до разметки.

Перемонтаж (хук вперёд, лишнее вон) — `template/recut.py`:

```bash
python3 recut.py silence ролик.mp4 58.5 60.5        # где тишина — там и режем
python3 recut.py cut ролик.mp4 whisper.json '[[20.48,24.78],[6.53,17.73],[24.79,83.36]]' --name A --fixes fixes.txt --caps '[0,1]'
```

Каждый вырезанный кусок проверяется повторным распознаванием (`whisper-cli` на вырезке): начинается и кончается ли он нужным словом. Союз «и» на стыке whisper иногда дописывает сам, спорный стык решается по спектру: перед «п» видна смычка-тишина.

## 2. Разметка кадра

Типичная запись автора — камера сверху, скринкаст снизу. Границу меряем по пикселям на нескольких кадрах (скачок средней яркости строки), а не на глаз. У «мясного прокси»: чёрная полоса 0–31, камера 32–811, скринкаст 812–1919. Чёрную полосу убираем, растягивая камеру до 812 строк:

```bash
ffmpeg -i A-raw.mp4 -filter_complex "[0:v]crop=1080:780:0:32,scale=1124:812:flags=lanczos,crop=1080:812:22:0,setsar=1[cam];[0:v]crop=1080:1108:0:812,setsar=1[site]" \
  -map "[cam]" -c:v libx264 -crf 15 -g 15 -an public/camera.mp4 -map "[site]" -c:v libx264 -crf 15 -g 15 -an public/site.mp4
ffmpeg -i A-raw.mp4 -vn -c:a aac -b:a 192k public/voice.m4a
```

## 3. Remotion-проект

`template/` копируется в папку ролика (`<ролик>/монтаж/`), затем `npm install`. В `public/` лежат `camera.mp4`, `site.mp4`, `voice.m4a`, `memes/`, `sources/`; в `src/project.json` — длительность и границы сцен, в `src/words.json` — тайминги слов из `recut.py`.

Ключевое из `src/lib.tsx`:

- **Время глобальное.** Сцены не оборачиваются в `<Sequence>`: `useT()` везде возвращает секунды от начала ролика, а тайминги берутся прямо из `words.json` (там уже +0,15 с поправки на ранний whisper).
- **`<Base>`** рисует камеру (0–811), скринкаст в нижней зоне (812–1919) и звук. Для вставок: `camera={null}` (без лица), `site={false}`, `audio="ins1-voice.m4a"`.
- **`<Bottom from to>`** — сцена нижней зоны 1080×1108, **`<Full from to>`** — сцена во весь кадр, раскрывается из нижней зоны.
- **Примитивы:** `prog`/`pop` (прогресс и упругое появление), `Stamp`, `Meme`/`MemeTop`/`MemeImg`, `ChatBg`/`ChatHeader`/`Bubble`/`Avatar`, `Words`, `Lines`, `SiteVideo` (скринкаст с наездом), палитра `C`, шрифты `GOLOS`, `MONO`, `HAND`. В `chat3.tsx` — реакции, волна голосового, клавиши; в `chars2.tsx` — нарисованные персонажи (робот, мясной человечек, коллега, лист, граната).
- **`AudioOff` + `Mix`:** `Mix` проигрывает один общий звук и в каждой сцене показывает выбранную версию.

Варианты — `src/V1.tsx…`, регистрируются в `src/versions.tsx`. Стоп-кадры для проверки:

```bash
npx remotion still src/index.ts V1 кадр.png --frame=$(python3 -c "print(round(13.5*30000/1001))") --log=error
```

Смотреть их глазами, склеивая полосой через `ffmpeg … hstack`. Варианты можно отдавать параллельным форкам: каждый пишет свой `V<n>.tsx` и хелперы в своём файле, а `lib.tsx`, `Root.tsx` и `build.sh` не трогает.

## 4. Сборка версии

`./build.sh V1 "<ролик> — монтаж 1"` рендерит и прожигает субтитры (`SUBS=…ass`). Если задан `END` — папка Remotion-проекта визитки с композицией `Iris` (круглая маска стягивается с лица в аватарку), скрипт берёт последний кадр, рендерит визитку (`FACE`, `FACEW` — центр и ширина лица) и приклеивает её к ролику.

## 5. Монтажный стол

`template/стол/`: `scenes.json` (по образцу `scenes.example.json`: версии и сцены с описанием каждого варианта) → `python3 prep.py` (кусочки со звуком, кадры, полоски, `data.json`) → `python3 server.py` (http://localhost:8091). Выбор и заметки сохраняются в `selection.json`, есть «Скопировать» и «Скачать MD». Итог по выбору: `./build.sh Mix …` с `--props` из `selection.json`, но обычно лучше отдельный `Final.tsx`, куда переносятся выбранные сцены с правками автора.

## 6. Вставки без лица

Отдельные композиции со своей длительностью (`I1F.tsx`, `I2F.tsx`): `<Base camera={null} audio=…>`. Верхнюю зону занимает тёмный блок с крупной типографикой (в нём лежат субтитры), нижнюю — основная анимация. Звук вставки вырезается из досъёмки, для неё отдельный `.ass` через `recut.py`. Сборка: `./build-ins.sh I1F 1 "вставка 1"`.

Склейка вставки в ролик (ffmpeg `concat`): резать основной ролик в тишине сразу после последнего слова, а продолжение начинать на кадр позже границы сцены. Иначе мелькает последний кадр прошлой сцены. Звук вставки обрезать по числу её видеокадров в самом `concat`, а не по `ffprobe` отдельного файла: разница в 2 кадра даёт сдвиг звука на 50–70 мс до конца ролика. После склейки сверить огибающую звука с исходником и расшифровать стыки. 

## 7. Источники и мемы

- **Факты:** поиск — любой веб-поиск (у автора — Exa и Tabstack), скриншоты — Playwright (viewport ~1100, scale 2, баннеры убрать), всё в `public/sources/` с `sources.json`. Выделения поверх скрина меряются на том же файле, что стоит в кадре: страница и её кроп сдвинуты друг относительно друга (у Груна на 152 px).
- **Мемы:** пустые шаблоны — `https://api.imgflip.com/get_memes`, русские подписи накладываются в Remotion. Шаблон кадрировать по содержанию; маленькие исходники после увеличения мылятся, это допустимо.

## 8. Грабли

- whisper ставит слова на 0,15–0,2 с раньше звука; слова на границе отрезка распределять по середине +0,2 с.
- Первые слова после тишины whisper может поставить внутрь тишины (у «похожих слов» 1,6 с тишины с «Это понятие» внутри). Начало куска проверять по огибающей громкости.
- Слова из одной правки `fixes.txt` получают одинаковое время, и фраза субтитров мигает. Время нужно раскладывать поровну по отрезку.
- `whisper.json` бывает невалидным UTF-8 (whisper режет кириллическую букву между токенами): читать через `subs.load_words`.
- Shell — zsh: цикл по строке с пробелами не разбивается на слова, аргументы передавать явно или функцией.
- `ffprobe -count_frames … -of csv=p=0` может вернуть число с запятой в конце: чистить через `tr -dc '0-9'`.
- В `public/` — только настоящие файлы: символические ссылки Remotion при сборке не переносит (404 на `camera.mp4`).
- Текст в картинке с наездом (ken burns) обрезается по краям. Такие картинки масштабировать контейнером, а не кропом.
